# FinanceFlow

Sistema de gestão financeira pessoal.

## Visão

O FinanceFlow será construído como uma aplicação completa para controle financeiro, com autenticação, contas bancárias, cartões, transações, orçamentos, metas, relatórios e acompanhamento de rendimentos.

## Arquitetura planejada

- Frontend: Flutter
- Backend: ASP.NET Core Web API
- Banco de dados: PostgreSQL
- Autenticação: JWT + Refresh Token

## Módulos

- Autenticação e perfil
- Dashboard financeiro
- Contas e instituições
- Cartões de crédito e faturas
- Transações
- Categorias
- Orçamentos
- Metas financeiras
- Transações recorrentes
- Relatórios
- Rendimentos e investimentos
- Calendário financeiro
